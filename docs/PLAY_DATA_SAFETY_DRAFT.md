# Play提出用データ確認表

2026-09-07。現行コードを確認して作成した回答案。Consoleへの申告は未実施。無料のTWAとして提供し、動画の配信・ダウンロード、広告配信、アプリ内購入は実装していない。

## データ種類と根拠

| 申告候補 | 実装で確認した情報 | 主な用途・送信先 |
|---|---|---|
| 個人情報: メールアドレス、ユーザーID、名前 | Supabase Auth、プロフィール名・ハンドル | ログイン、アカウント管理、公開プロフィール / Supabase |
| 写真 | 任意のプロフィール画像 | プロフィール表示 / Supabase Storage |
| アプリのアクティビティ: その他のユーザー生成コンテンツ | 視聴記録、評価、感想、メモ、自己紹介、通報理由・対象の写し | アプリ機能、コミュニティの安全管理 / Supabase |
| アプリのアクティビティ: アプリ内検索履歴 | 入力された作品検索語（履歴保存機能はなくても、端末外に送信する） | 作品検索 / AniList、Annict（自サーバー経由） |
| アプリのアクティビティ: アプリの操作 | ページ閲覧、インストール操作、追加機能への関心 | 分析 / Vercel Analytics、GA4（本番設定がある場合） |
| アプリの情報・パフォーマンス: その他のパフォーマンスデータ | Core Web Vitals | 性能分析 / Vercel Speed Insights |
| デバイスまたはその他のID | 任意のWeb Push購読情報、GA4のCookie識別子 | 通知 / Supabase・ブラウザの通知配信基盤、分析 / Google |
| 位置情報: おおよその現在地 | GA4のIP由来の地域判定 | 分析 / Google。端末の位置情報権限は要求しない |

最終的な分類、エフェメラル処理、必須/任意の選択はConsoleの定義と本番サービス設定で確認する。ゲストの端末内記録はlocalStorage保存だが、検索・解析などまで「データ収集なし」にはならない。任意のログイン、画像設定、通知許可と、アプリ内で停止スイッチがない解析は区別する。Firebase Android SDKは搭載していないため、そのSDK用回答をそのまま転記しない。

## 共有・削除・保護

- Supabase/Vercel等への処理委託を「共有」から除外できるかは、各契約・利用設定とGoogleのサービスプロバイダ例外に照らして判断する。公開プロフィール・投稿した感想の他ユーザーへの表示も確認する。外部サービスの数だけで回答しない。
- 通報の送信者と内容、ブロック関係は相手に通知・一般公開しない。
- プライバシーポリシー: `https://animelog.jp/privacy`。
- アカウント削除URL: `https://animelog.jp/delete-account`。Web修正の公開後にURLとログインからの削除経路を検証する。削除テストは専用アカウントで行う。
- 通信先はHTTPS。独立したセキュリティ審査の取得実績はないため、取得済みとは回答しない。
- 認証DB・関連テーブル・プロフィール画像の削除と、ブラウザ内データ、書き出し済みファイル、解析集計、各サービスのバックアップ/ログの保存期間は区別する。

## 提出前に確定する項目

1. 本番GA4の有効状態、Google Signals/広告連携、データ共有・保持設定。コードからは管理画面側の設定まで確定できない。
2. プライバシーポリシーにAnnict、Speed Insights、お問い合わせのGoogleフォームを明示する。「完全に削除」「匿名」「個人情報は送信されない」の対象を実装・サービス設定に合わせて明確にする。
3. 実際の作品画像・説明・ユーザー投稿に基づくIARC回答と対象年齢。「暴力・性的表現はすべてなし」を一律に選ばない。
4. Play審査用ログイン情報は専用アカウントを使い、公開資料やPR本文に記載しない。

根拠: [Google PlayのData Safety回答ガイド](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)。この表はコードからの整理であり、管理画面の設定や実機通信の確認を代替しない。
